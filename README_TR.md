# Instagram Agent Skill (Türkçe Sürüm & Web Arayüzü)

Instagram hesabınızı profesyonelce büyütmek için geliştirilmiş **13 yapay zeka komutu (skill)**, **5 yerel Python test/analiz motoru** ve **GitHub Pages web stüdyosu**.

> Bu proje, [Jake Schincariol](https://github.com/Jakeschincariol/instagram-agent-skill) tarafından geliştirilen açık kaynaklı (MIT Lisanslı) projenin **Türkçe yerelleştirmesi ve interaktif Web Arayüzü (GitHub Pages)** eklenmiş sürümüdür.

---

## 🌟 Öne Çıkan Özellikler

1. **🌐 Canlı Web Stüdyosu (GitHub Pages):** Hiçbir şey kurmadan doğrudan tarayıcı üzerinden çalışan Kanca Puanlayıcı, 125 Karakter Akış Simülatörü, Beat Sheet ve 26 Kanca Kataloğu.
2. **🎯 26 Kanıtlanmış Türkçe Kanca Formülü (`hooks_tr.json`):** Türkçe konuşma diline, devrik ve kurallı cümle yapılarına tam uyumlu viral formüller.
3. **⚡ Yerel Python Araçları:**
   * `hookscore.py`: Kancanızı puanlar, *"Selam arkadaşlar..."* gibi ölü açılışları ve *"Kaydırmayı durdur"* klişelerini eler.
   * `beats.py`: Dakikada 165 kelime hızına göre Reel senaryosunu saniye saniye zamanlar.
   * `caption.py`: Akışta "...devamı"ndan önceki ilk 125 karakteri gösterir, 5 hashtag sınırını denetler.
   * `humanize.py`: Yapay zeka klişelerini (*"dijital dünyada", "çığır açan"*) ve görünmez filigranları temizler.
4. **🔒 Sıfır Ban Riski:** Instagram şifrenizi istemez, bot gibi otomatik paylaşım yapmaz. Kopyala-yapıştır hazır teslim eder.

---

## 🚀 GitHub Pages Web Arayüzünü Başlatma

1. Bu depoyu kendi GitHub hesabınıza Fork edin veya yükleyin.
2. Deponuzun **Settings > Pages** sekmesine gidin.
3. **Branch** kısmından `main` (veya `master`) ve klasör olarak `/ (root)` veya `/docs` seçip **Save** deyin.
4. Birkaç saniye içinde `https://kullaniciadiniz.github.io/instagram-agent-skill/` adresinde kendi web stüdyonuz yayına girecektir!
